# 수학 확률 탐구 실험실 프로

주사위 실험과 대량 시뮬레이션으로 상대도수와 이론 확률을 비교하는 도구. (분류: 수학)

## 어떻게 실행하나요

1. 이 폴더의 `index.html`을 더블클릭해 브라우저(Chrome·Edge 권장)로 엽니다. 설치도, 로그인도 필요 없습니다.
2. 또는 이 저장소 전체를 내려받은 뒤 터미널에서 `python3 -m http.server` 를 실행하고 `http://localhost:8000/dice-math-lab/` 를 엽니다.
3. 온라인 버전: https://sonssam-hub.bluesskssk.workers.dev/apps/dice-math-lab/

> 상단 파란 막대(소리·전체화면)는 저장소 루트의 `common-nav.js` 를 씁니다. `dice-math-lab` 폴더만 따로 옮기면 이 막대는 나오지 않고 도구는 그대로 동작합니다.

## 사용 전 확인

- 로그인: 없음 / 비용: 무료
- 인터넷: 필요 없음(처음부터 이 폴더 안의 파일만 씁니다)
- 저장되는 정보: 저장하는 정보가 없습니다. 통계 CSV는 내 기기로만 내려받습니다.
- 외부 서버로 전송: 없음
