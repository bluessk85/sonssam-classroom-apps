# 구글 스프레드시트 공공데이터 실습 가이드북

구글 스프레드시트로 CSV 열기·수식·막대/원그래프·해석 문장까지 7단계로 안내하는 학생용 실습 가이드. (분류: 실과·정보·수학)

## 어떻게 실행하나요

1. 이 폴더의 `index.html`을 더블클릭해 브라우저(Chrome·Edge 권장)로 엽니다. 설치도, 로그인도 필요 없습니다.
2. 또는 이 저장소 전체를 내려받은 뒤 터미널에서 `python3 -m http.server` 를 실행하고 `http://localhost:8000/data-graph-lab/` 를 엽니다.
3. 온라인 버전: https://sonssam-hub.bluesskssk.workers.dev/apps/data-graph-lab/

> 상단 파란 막대(소리·전체화면)는 저장소 루트의 `common-nav.js` 를 씁니다. `data-graph-lab` 폴더만 따로 옮기면 이 막대는 나오지 않고 도구는 그대로 동작합니다.

## 사용 전 확인

- 로그인: 없음 / 비용: 무료
- 인터넷: 필요 없음(처음부터 이 폴더 안의 파일만 씁니다)
- 구글 스프레드시트 사이트(sheets.google.com)는 학생이 직접 접속합니다. 이 폴더의 파일은 구글과 통신하지 않습니다.
- 저장되는 정보: 저장하는 정보가 없습니다. 내장 CSV는 6개 시·구의 연습용 예시 표입니다(실제 통계로 인용하지 마세요). 실습에는 학생의 구글 계정(구글 스프레드시트)이 필요합니다.
- 외부 서버로 전송: 없음
